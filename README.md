# Framecraft

An easy-to-use guide for getting Vivecraft working natively on Steam Frame! This is not a new mod of MCVR or anything unique, just a simple way to set up Vivecraft on Frame. I didn’t really do much other than put together an installer for easy accessibility in 3 weeks, with some help from my friend Jodie. I recommend changing your button layout, but the current layout works fine. You can configure video settings in game if needed as well. Have fun!

## REQUIREMENTS

- A Steam Frame connected to Wi-Fi
- A Microsoft account that owns Minecraft: Java Edition
You do not need Prism Launcher or anything else! The install handles that for you.

## INSTALL

1. Press the Steam button, go to Power, and choose Switch to Desktop.
2. Open the app launcher, search for Konsole and open it.
3. Paste this line and press Enter:

```
curl -fsSL https://raw.githubusercontent.com/hardwaresteam/Framecraft/main/framecraft-setup.sh | bash
```

4. When Prism Launcher opens, click OK to import, then sign in with your Microsoft account (account button, top right).
5. Close Prism Launcher and double-click Return to Gaming Mode.

## PLAY

1. Start Framecraft from your Steam library.
2. The first time, it asks to restart. Close it and start it again.
3. On the title screen, make sure it says VR: ON.

 ## CONTROLS

| BUTTON | ACTION |
| --- | --- |
| A | Place / eat / left click |
| B, X, Y | Radial menu (pick block, drop item, etc.) |
| D-pad down | Inventory |
| D-pad left, up or right | Pause menu |
| Left stick click | Jump |
| Right stick click | Crouch |
| Right trigger | Break block / attack |
| Left trigger | Teleport |

I will admit, the automatically assigned controls are janky and I don’t like them. There will be a custom community layout option soon for better keybinds. However, for now you can manually change these if you’d like.
Press the Steam button in game, go to Settings > Controllers > Manage Controller Bindings, and choose Vivecraft. Then you can configure from there.
